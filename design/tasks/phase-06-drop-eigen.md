# Phase 6: drop Eigen

Goal: `core_types/math` replaces Eigen everywhere; `third_party/eigen`
deleted. References: lite-removals.md §4. Independent of P7.

### P6-T01 Inventory Eigen usage
Depends: P5-T07
Do:
- `git grep -n "Eigen::" -- library tools > design/lite-eigen-uses.txt`; classify each line: type alias only, arithmetic, decomposition (SVD/eigen/LU/Cholesky/inverse), `Map`/block/expression idioms, python caster. Record counts per category in STATUS.md.
Done when:
- Inventory committed.

### P6-T02 `core_types/math` library
Depends: P6-T01
Do:
- Implement `vector.h`, `matrix.h`, `rotation.h`, `covariance.h`, `similarity.h`, `decomp.h` per lite-removals.md §4.1. Keep vital typedef names. Header-only, constexpr where possible, no allocation for fixed sizes; `dynamic_matrix<T>` for DLT.
- Unit tests: identities, inverse*A = I, rotation round-trips, SVD reconstruction error < 1e-12 on random 6x4 / 3x3 / 4x4, Cholesky on SPD, least squares vs closed form. Golden values recorded now from Eigen (`tests/golden/math/*.json`, generated by a one-off tool built while Eigen is still present).
Done when:
- `ctest -R core_types_math` passes; no Eigen include in `core_types/math`.

### P6-T03 Port `core_types` off Eigen
Depends: P6-T02
Do:
- Port `vector`, `matrix`, `point`, `rotation`, `covariance`, `homography*`, `transform_2d`, `similarity`, `camera_intrinsics`, `camera_perspective`, `camera_rig`, `camera_perspective_map`, `landmark*`, `feature*`, `bounding_box`, `polygon`, `descriptor` (if it uses Eigen), `essential_matrix`, `fundamental_matrix` (drop if unused after P5-T06). Keep public method names; replace `.array()`, `.cast<>()`, `Eigen::Map` idioms with explicit loops or helpers.
- Python casters: numpy <-> `vector<N,T>`, `matrix<R,C,T>` via buffer protocol in `core_types/casters.h`, replacing `eigen_class.h` usage.
Done when:
- `git grep Eigen:: -- library/core_types` empty; unit tests and python type tests pass.

### P6-T04 Port `algorithm_framework`, `pipeline_framework`, `utilities`, `file_io`
Depends: P6-T03
Do:
- Remaining Eigen uses in config helpers (`config_block` Eigen conversions), type traits, `camera_io`, `camera_rig_io`, `read_transform_homography_json`, homography writer.
Done when:
- `git grep Eigen:: -- library/{algorithm_framework,pipeline_framework,utilities,file_io}` empty; tests pass.

### P6-T05 Port `measurement` and `object_trackers`
Depends: P6-T04
Do:
- `triangulate` (DLT + inhomogeneous via `decomp.h`), `measurement_utilities`, `pair_stereo_*`, `calibrate_cameras_from_tracks_process` (numeric optimisation moved to python `viame.measurement.calibrate_from_tracks` registered under the same process name; C++ process becomes a thin python-backed process or the process is re-registered in python), `optimize_stereo_cameras` (python scipy `least_squares`, same name), `compute_association_matrix_from_features`.
- Golden: measurement pipelines (`measurement_*`) outputs within 1e-3 relative on lengths; triangulation unit test vs golden.
Done when:
- `git grep Eigen:: -- library` returns only `image_processing`/`object_detectors` if any remain; GOLDEN passes.

### P6-T06 Port the rest and delete Eigen
Depends: P6-T05
Do:
- Any remaining users (`image_processing` homography warps, `object_detectors` windowed geometry, `tools`). Delete `third_party/eigen`, `Eigen3::Eigen` target, every `find_package(Eigen3)`.
Done when:
- `git grep -n "Eigen" -- library tools cmake CMakeLists.txt third_party` empty; build from clean; BASELINE, CRITICAL, GOLDEN pass.
