# What each file asks OpenCV for (P7-T01)

Generated by the inventory pass of P7-T01, from `git grep -ln "opencv2/"`
over `library/`, `tools/`, `plugins/` and `python/`. The areas are
`lite-removals.md` section 2's. `plugins/` is in scope even though the plan's
task text names only `library/` and `tools/`: phase 2 has not moved those
directories yet, so most of what phase 7 describes still lives there.

`plugins/pytorch/learn` is excluded -- the python packages vendored there
carry their own OpenCV and become wheels in phase 9.

pair below is one the install actually registers.

under the same name -- or the old name becomes an alias of a new one, as

## The processes OpenCV backs

`direct` means the process's own header or source includes `opencv2/`;
`library` means something else in the same directory does. The second is
not a weaker claim -- a process class usually keeps OpenCV out of its
header and reaches it through the algorithm it wraps, and the library is
the granularity phase 7 removes things at.
