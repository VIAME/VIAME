# torch for a CUDA 13 build, layered over requirements.txt. This is the
# default variant: the plain `viame` wheel.
#
# CUDA 13's nvcc starts at compute_75, so this has no GPU support on Pascal
# (6.0, 6.1) or Volta (7.0). Those users want the +cu12 wheel.

# No nvidia-* here on purpose: nothing CUDA is bundled and nothing is pinned.
# A plain `pip install torch` brings the whole runtime -- cuda-runtime,
# cublas, curand and cudnn, via cuda-toolkit -- and those are the copies this
# wheel's RUNPATH points at. Whatever CUDA torch chose is the one we use.
#
# The floor is what makes that true: torch moved to cu13 at 2.11. There is no
# ceiling, which is a deliberate bet that torch's next CUDA bump comes with a
# VIAME rebuilt against it. If it does not, the symptom is the loader falling
# back to a system CUDA, so check `ldd` on a binding after a torch upgrade.
torch>=2.11
torchvision>=0.18.1
