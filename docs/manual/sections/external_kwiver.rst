====================
KWIVER Documentation
====================

VIAME is built on top of `KWIVER`_, which provides the core data types, the
pipeline framework and many of the algorithms VIAME pipelines use. Its manual
is hosted separately:

.. _KWIVER: https://github.com/Kitware/kwiver

* `Core C++/Python Object Types`_ (vital)
* `Core Pipelining Architecture`_ (sprokit)
* `Basic Pipeline Nodes`_ (arrows)
* `Python Bindings`_
* `KWIVER Full Manual`_
